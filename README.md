# 🍥 Shinobi Renascido — RPG de Naruto Clássico

Protótipo de fã **não oficial** criado para jogar pelo celular. História inspirada no início do episódio 1 de Naruto Clássico.

**🎮 Jogar online:** https://educacaomggovbr00-web.github.io/shinobi-renascido-rpg/ (quando GitHub Pages estiver habilitado e a publicação concluída).

## Personagem

Henrique Uchiha, 12 anos. Sua consciência é Rick-138, de inteligência extraordinária, mas sem conhecimento prévio do universo ninja. Henrique aprende uma técnica após observá-la uma única vez, respeitando os limites de chakra do corpo. Foi criado por Hana e Daichi, pais adotivos de poucos recursos, em Konoha. O jogador controla exclusivamente as falas e ações de Henrique.

## O que já funciona

- Interface de chat adaptada para Android;
- Cena inicial na casa dos pais, antes da Academia Ninja;
- Relógio, status, inventário e salvamento local automático;
- Caminho para a Academia, aprendizado de Bunshin por observação e gasto de chakra ao usá-lo;
- Modo demonstrativo com respostas predefinidas, **não é uma IA conversacional real**.

## Jogo offline

Abra `site/index.html` diretamente no navegador que suporte arquivos HTML locais. Sem necessidade de computador. Para publicar online, GitHub Pages usa o workflow em `.github/workflows/pages.yml`.
